ABOUT THIS GAME

关于这款游戏

《Paper Man》是一场发生在一张纸上的逃亡。玩家先在三维房间中自由探索——这是一个失败游戏制作者的住所：杂乱、无窗、灯光昏暗，墙上贴满他热爱的游戏海报。触发三件关键物品的剧情后，玩家被引导至电脑桌前，按 Tab 进入纸面，开始操控 2D 小人。

小人唯一的资源是构成自己身体的线条。每画一段跳跃平台，身体就短一分；每一关藏着一把钥匙，拿到它才能进入下一关，也会让线条重新变长。当最后的门锁横在面前而线条不够时，玩家必须回头重走旧关卡——像所有创作者一样，在反复折返中攒够走出去的力量。

创作灵感来自围绕职场焦虑、自我实现与人生选择的讨论：许多心怀理想的人被稳定却重复的生活束缚，逐渐陷入自我怀疑。《Paper Man》想回应的，正是人们渴望突破舒适圈、重新寻找生活方向的共同需求。

GAMEPLAY

游戏机制

核心循环 · CORE LOOP

消耗自身线条资源绘制跳跃平台，与纸面原有平台结合前进；每关一把隐藏钥匙，获取后方可进入下一关，并增加线条长度资源。小人无法离开纸面——玩家需要在"身体的线条"与"通关的路径"之间持续做规划。

  1. 013D 房间探索，触发三件物体剧情
  2. 02被引导至电脑桌前，Tab 进入 2D 模式
  3. 03消耗线条闯关，收集各关隐藏钥匙
  4. 04通过 1–3 关，获得 key5，抵达墙上海报
  5. 05开锁失败：线条不足 → 回退旧关积攒资源
  6. 06成功开门，3D 角色走出房间，游戏成功

DEVELOPMENT

开发迭代 · 四版核心机制

VERSION 01

核心概念验证

确立"画线即消耗身体"的核心机制，验证最基础的跳跃平台玩法。

VERSION 02

钥匙与资源循环

加入隐藏钥匙与线条长度资源的增长循环，形成"收集 → 变长 → 走得更远"的正反馈。

VERSION 03

云朵 → 线稿 → 瀑布

玩家从云朵图进入素描线稿场景，翻越斜坡与山，在几何体背后找到 key4；画线抵达右上角平台后进入 "Line Rider" 过渡图，在曲线图中跳跃绘制平台，顺着衣柜垂下的图纸一路向下，抵达"瀑布"最底端。

VERSION 04

柜门、海报与最后一道锁

柜门开合之间完成 2D 与 3D 场景的"粘贴"切换；最后的门锁前线条不足，玩家需重返旧地图积累资源。门锁打开，2D 小人帮助三维世界的游戏失败者走出房间，前往光明的世界——游戏成功。
